# Features Backlog

A running list of ideas for future Hoops features and improvements.

## 1. Bonus Gem Above the Rim

Spawn a bonus gem that floats above the rim for a limited time. The player only collects it if they make the shot before the gem disappears.

- Gem appears periodically (timed window or event-triggered)
- Visible countdown / fade-out animation as time runs out
- Reward is only granted on a made basket while the gem is still present
- Consider rarity tiers (common / rare / legendary) with different reward values

## 2. Improve the "On Fire" Orange Line

The orange trail/line that shows while the player is on fire needs a visual polish pass.

- Replace flat orange line with a more polished effect (gradient, particles, glow)
- Better blending with the ball trail
- Consider animated flame/ember particles instead of a hard line
- Tune intensity so it reads well against all backgrounds

## 3. Tickets & Ball Skin Store

Introduce a soft currency ("tickets") that players earn through play and spend on cosmetic ball skins.

### Earning tickets
- Games played
- Achievements unlocked
- Milestones (streaks, high scores, fire activations, etc.)
- Daily / weekly bonuses

### Spending tickets
- New "Store" screen
- Ball skins as the first cosmetic category (different colors, patterns, materials, effects)
- Potential future categories: rim skins, court themes, trail effects

### Considerations
- Persist ticket balance and owned skins locally (and/or server-side if accounts exist)
- Equip / preview flow before purchase
- Pricing tiers so there's both quick wins and aspirational items
